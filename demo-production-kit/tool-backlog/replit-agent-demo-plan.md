## Test Workflow

**[SIMULATED — replace with actual recorded steps]**

1. Open replit.com — show the homepage
2. Click "Create Repl" → choose "Agent" mode
3. Type a plain-English app description: "Build a simple lead capture page with a name and email form. Store submissions in a database. Show a thank-you message after submission."
4. Watch Replit Agent: plan the steps, write the code, install dependencies, set up the database
5. Show the code being generated (terminal + editor) — you don't need to understand it
6. When Agent finishes, click the preview URL — show the live app
7. Submit a test form entry — show it appears in the database
8. Show the Replit deployment URL — the app is live on the web
9. Optional: ask Agent to "add an email notification when a new form is submitted" — show it updating the app

## Notes

- Replit Agent uses AI credits — verify current free allocation before recording.
- The demo app should be simple enough that Agent succeeds cleanly. Complex apps may need debugging, which is hard to show without confusing viewers.
- If Agent hits an error, don't cut it — show how Agent self-corrects. That's impressive content.
- Compare with Lovable, Bolt.new, v0 — all in the same "AI app builder" category. Strong series angle.
- Do not deploy apps with real user data or production credentials during demo recording.
