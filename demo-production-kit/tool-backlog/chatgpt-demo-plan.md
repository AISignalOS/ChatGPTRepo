## Test Workflow

**[SIMULATED — replace with actual recorded steps]**

1. Open chatgpt.com — show the clean interface
2. Open Settings → Custom Instructions — show the system-level persona setup
3. Start a new chat — type a content research prompt: "Give me 10 blog post ideas for a solopreneur selling AI automation services"
4. Follow up: "Take idea #3 and write a full H1/H2/H3 outline with 3 bullet points per section"
5. Follow up: "Write the intro paragraph for this post in a conversational, direct tone"
6. Show the result — evaluate quality honestly
7. Optional: use the "Improve" follow-up to show iteration
