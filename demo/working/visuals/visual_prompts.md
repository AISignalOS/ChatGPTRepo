# Visual & Image Generation Prompts

Use these prompts with Midjourney, DALL-E 3, Stable Diffusion, or Canva AI.

---

## Thumbnail — YouTube / LinkedIn

**Primary thumbnail prompt:**
> "Dark terminal window on a black background, neon green text streaming line by line, a small glowing brain icon in the top-right corner, bold white text overlay reading 'Build AI Chatbot in 50 Lines', clean developer aesthetic, high contrast, photorealistic"

**Alt thumbnail (face + code):**
> "Split screen: developer looking surprised on left, VS Code window with Python code on right, blue-purple gradient background, bold yellow text 'Claude API Tutorial', YouTube thumbnail style"

---

## Short-Form Cover / First Frame (TikTok / Reels / Shorts)

**Prompt:**
> "Vertical 9:16 format, dark background, terminal window center frame, green text streaming fast like The Matrix, white text at top: 'AI Chatbot in 60 Seconds', glowing purple border, high energy"

## B-Roll Scene Prompts (for AI video generators like Runway, Pika, Sora)

### Scene 1 — Hook / Chatbot running
> "Close-up of a terminal window, green monospace text appearing line by line as if being typed by AI, dark office background, cinematic, 4K"

### Scene 2 — API Key setup
> "Browser window showing a dashboard with an API key partially visible, blurred sensitive fields, developer desk setup, warm lamp lighting"

### Scene 3 — Code editor
> "VS Code editor open with Python code highlighted in blue and orange, dark theme, developer hands typing, shallow depth of field, 4K cinematic"

### Scene 4 — Streaming comparison
> "Split-screen animation: left side text appears all at once, right side text streams in letter by letter, both on dark terminals, labeled 'Before' and 'After'"

### Scene 5 — Cost savings / Prompt caching
> "Animated bar chart showing cost dropping 90%, green downward arrow, minimalist tech infographic style, dark background"

### Scene 6 — Outro / GitHub
> "GitHub repository page with a star counter ticking up, animated, dark GitHub theme"

## Animation / Motion Graphics Prompts

### Code typing animation
> "Screen recording style animation: Python code types itself into a dark terminal, each line appears with a 0.3s delay, cursor blinking, syntax highlighting in VS Code colors"

### Token streaming animation
> "Text appears word-by-word from left to right in a chat bubble, light grey bubble on dark background, smooth fade-in per token, 2-second loop"

### Architecture diagram
> "Clean technical diagram: User → Python Script → Anthropic API → Claude Model → Response, connected by animated arrows, dark background, white nodes, blue connecting lines, modern SaaS style"
